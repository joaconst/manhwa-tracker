Conectá tu cuenta

El dashboard lee tu biblioteca de ManhwaWeb directo desde tu navegador. No hay servidor ni base de datos: tu token se queda acá.

  1. 1
    Instalá el userscript

    Violentmonkey + manhwaweb-tracker.user.js. Después abrí el dashboard desde el botón Mis lecturas y se conecta solo.

  2. 2
    O pegá tu token a mano

    En ManhwaWeb: F12 → Application → Local Storage → tokenCommers. Copiá el valor y pegalo acá.

Tu token equivale a tu sesión: no lo compartas ni lo subas a ningún lado.
